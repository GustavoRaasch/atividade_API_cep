Atividade ViaCEP

1. Nome do projeto
Consulta de CEP com ViaCEP.

2. Objetivo
Criar uma página simples para consultar informações
de endereços através de um CEP.

3. API utilizada
Foi utilizada a API simples ViaCEP.

4. Tecnologias
HTML

CSS
5. Como utilizar
Digite um CEP válido no campo de pesquisa e clique
no botão "Buscar".

6. Resultado
A página apresenta o CEP, rua, bairro, cidade e estado
encontrados pela API.
